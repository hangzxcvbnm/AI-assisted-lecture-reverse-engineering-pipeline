# 课程视频自动拆分器

> 从教学视频中自动提取 PPT 页面、生成带时间戳的讲稿，并将 PPT 与对应讲稿进行自动对齐，为 AI 辅助重构课程、PPT 和演讲稿提供结构化素材。

---

## ✨ 项目简介

课程视频自动拆分器（Lecture Splitter）是一个用于处理课程、讲座和教学视频的自动化工具。

当你只有一个包含：

- PPT 画面
- 老师讲课声音
- 视频字幕（如果有）

的 MP4 视频时，本项目可以自动完成：

```text
课程视频
   │
   ├── 🎙️ 语音识别
   │       ↓
   │   带时间戳的讲稿
   │
   ├── 📑 PPT 页面检测
   │       ↓
   │   自动识别翻页
   │
   ├── 📸 PPT 截图
   │       ↓
   │   每页 PPT 一张图片
   │
   └── 🔗 时间轴对齐
           ↓
      PPT ←→ 对应讲稿
